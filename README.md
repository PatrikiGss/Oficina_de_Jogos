Repositório criado para o desenvolvimento do jogo da oficina de jogos da disciplina de Atividade de Extensão III. O projeto ainda está em estágio embrionário.

Todo o desenvolvimento deve ser realizado em branches separadas, criadas de acordo com a feature que será trabalhada. Após a conclusão da feature, deve ser aberto um Pull Request para análise e revisão dos demais membros da equipe.

Nunca desenvolva uma feature diretamente na main. Alterações diretamente na main devem ser restritas a ajustes pontuais.

ideia inicial sera de um jogo estilo ping pong onde conectados localmente eles possam se enfrentar. e o desenvolvimento em sala sera pair programing
